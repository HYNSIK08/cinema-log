영화의 감동을 기록하는 공간 시네마 로그

TMDB 실시간 최신 영화 정보 확인부터 개인 감상평 작성, 장르별 필터링까지 나만의 영화 아카이브를 구축해보세요.

✨ 주요 기능

🔥

TMDB 실시간 API 연동

현재 인기 있는 트렌드 영화와 최신 영화 데이터를 실시간으로 조회하고 검색할 수 있습니다.

✍️

자유로운 감상평 기록

영화 제목, 장르, 작성자, 감상 후기를 기록하고 조회수 및 추천(좋아요) 기능을 제공합니다.

🎯

스마트 필터링 & 검색

장르별 카테고리 필터와 제목 실시간 검색 기능으로 원하는 감상평을 빠르고 쉽게 찾을 수 있습니다.

🔒

관리자 모드 시스템

관리자 인증을 통해 게시글 숨김/노출 토글 관리 및 일괄 삭제 기능을 안전하게 제공합니다.

💡 이용 안내

  • 감상평 작성 TMDB 검색 카드의 영화를 클릭하면 해당 영화 제목이 자동 입력된 상태로 편리하게 감상평을 작성할 수 있습니다.
  • 데이터 보존 Clever Cloud MySQL 데이터베이스와 클라이언트 LocalStorage의 하이브리드 구조로 데이터 안정성을 보장합니다.
  • 콘텐츠 보호 무단 복사 및 도용을 방지하기 위해 마우스 우클릭, 드래그, 개발자 도구 단축키 차단 기능이 적용되어 있습니다.

지금 바로 당신의 첫 영화 감상평을 남겨보세요!
